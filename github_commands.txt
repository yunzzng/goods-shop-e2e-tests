Project_S 깃허브 명령어 가이드

1. Git 사용자 정보 설정 (최초 1회)
git config --global user.name "YOUR_NAME"
git config --global user.email "YOUR_EMAIL"

2. 현재 저장소 상태 확인
git status

3. 파일 스테이징
git add .

4. 커밋 생성
git commit -m "Initial commit"

5. 브랜치 이름을 main으로 변경
git branch -M main

6. GitHub 원격 저장소 연결
git remote add origin https://github.com/YOUR_ID/YOUR_REPOSITORY.git

7. 연결된 원격 저장소 확인
git remote -v

8. GitHub에 처음 푸시하기
git push -u origin main

9. 이후 변경 사항 푸시
git add .
git commit -m "Update project"
git push

10. 최신 변경 사항 가져오기
git pull origin main

11. 다른 컴퓨터에서 저장소 복제
git clone https://github.com/YOUR_ID/YOUR_REPOSITORY.git

12. 선택 사항: 가상환경 및 IDE 파일 무시하기
.gitignore 파일을 만들고 아래 예시를 추가
.venv/
__pycache__/
.idea/
